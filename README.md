# pairwise-wide-gamut

同一张 HDR 贴图在编辑器里正常，进游戏后高光和肤色都偏：纹理导入按 sRGB 解码，渲染目标却是线性，中间没有做色彩空间转换；广色域 Display-P3 素材被当成 sRGB，红色溢出；色调映射只处理亮度，色相在暗部偏移；LUT 是 3D 但采样用 2D 切片，蓝通道插值错位；曝光补偿在色调映射前后各做一次，亮部被压两次；透明混合在线性空间做，alpha 边缘发灰；截图和录屏走 sRGB 编码，游戏内是 HDR，颜色对不上；不同平台的 gamma 默认值不一致，同一配置在主机和 PC 上不同；色彩分级节点顺序固定，先曲线后 LUT 导致饱和度过高；批量素材导入时没有按色彩空间分组，单个 P3 贴图导致整批偏色。color/wide_gamut.py 是核心，tests/test_wide_gamut.py 15个红。要修的是：统一线性工作流；P3 转换；色相保持映射；3D LUT 采样；曝光只做一次；线性混合；输出编码匹配；平台 gamma 校准；分级顺序可配置；按色彩空间分组。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
